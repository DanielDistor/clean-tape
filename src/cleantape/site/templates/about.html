What this is

{{ title }}: {{ tagline }}

"The tape" is trader slang for the market data feed — the stream of prices everyone reads. Clean Tape checks that feed before it reaches the screen.

It is a portfolio project that mirrors four internal tools an investment-technology team builds: a morning dashboard, a pipeline that turns vendor file drops into a clean queryable dataset, an automated end-of-day report that replaces a manual Excel workflow, and checks that flag when a feed is late, incomplete or doesn't add up.

How it works

  1. GitHub Actions runs twice each weekday (morning and evening New York time).
  2. Each run downloads FRED, Yahoo Finance, Nasdaq (fallback) and ECB data, saves every response untouched, and records it in a manifest.
  3. Responses are normalised into one table of observations (date, instrument, source, value). Missing values stay missing.
  4. Data-quality checks run: freshness, completeness, schema, validity, stale values, outliers and cross-source consistency.
  5. Spreads, changes, z-scores and the mock portfolio P&L are computed, then this site and the end-of-day report are generated. Anything that failed a check is marked, never shown as if it were fine.

Data sources

  • FRED (St. Louis Fed): Treasury yields, 10y breakeven, HY OAS, broad dollar index, WTI spot.
  • Yahoo Finance via yfinance: equity ETFs, VIX, FX, front-month futures, commodity ETFs.
  • Nasdaq quote history: fallback for US ETFs when Yahoo fails (unadjusted closes).
  • ECB reference rates: independent second source for FX.

Limitations

  • End-of-day free data only; Yahoo is unofficial and can break or block cloud IPs.
  • The bond-market calendar approximates SIFMA (federal holidays + Good Friday); early closes are not modelled.
  • Futures are continuous front-month series, not roll-adjusted — display only.
  • P&L and shocks are linear and simplified; the portfolio is MOCK.
  • GitHub's scheduler is not punctual; runs may land late in their window or be skipped.
