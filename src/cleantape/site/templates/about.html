"The tape" is trader slang for the market data feed — the stream of prices everyone reads. Clean Tape checks that feed before it reaches the screen.

It mirrors four internal tools an investment-technology team builds: a morning dashboard, a pipeline that turns vendor file drops into a clean queryable dataset, an automated end-of-day report that replaces a manual Excel workflow, and an engine that flags when a feed is late, incomplete or doesn't add up.

Each check rates every series OK, WARN or FAIL; the run takes the worst. A FAIL strikes the number through on this site, removes it from the P&L and the top movers, puts a red box at the top of the end-of-day report, and turns the GitHub Actions run red. An empty input or a crashed check is itself a FAIL — the engine never passes silently. Cross-source tolerances are calibrated from 2021→today history (p99 / p99.9 × 1.5). Live results: Health.

How a run works

  1. Pull — twice each weekday (morning and evening New York time) GitHub Actions fetches FRED, Yahoo Finance (Nasdaq as fallback) and ECB data and saves every response untouched with a manifest entry.
  2. Clean — responses are normalised into one table of observations (date, instrument, source, value). Missing values stay missing; unfinished intraday bars are never stored.
  3. Check — the 7-check engine above runs.
  4. Publish — spreads, changes, z-scores and the mock P&L are computed, then this site and the end-of-day report (HTML + Excel) are generated with every check result attached.

Limitations

  • End-of-day free data only; Yahoo is unofficial and can break or block cloud IPs.
  • The bond-market calendar approximates SIFMA (federal holidays + Good Friday); early closes are not modelled.
  • Futures are continuous front-month series, not roll-adjusted — display only.
  • P&L and shocks are linear and simplified; the portfolio is MOCK.
  • GitHub's scheduler is not punctual; runs may land late in their window or be skipped.
